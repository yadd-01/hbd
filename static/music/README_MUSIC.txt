# Instruksi Musik

## Cara Menambahkan Lagu "Lovers Rock"

1. Download file MP3 lagu "Lovers Rock" - TV Girl
2. Rename file menjadi `lovers-rock.mp3`
3. Letakkan file di folder: `static/music/lovers-rock.mp3`

## Format yang Didukung
- MP3 (Recommended)
- WAV
- OGG

## Catatan
- Gunakan lagu yang sudah di-download secara legal
- File harus berformat MP3 untuk kompatibilitas terbaik
- Ukuran ideal: 3-5 MB
